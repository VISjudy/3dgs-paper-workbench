## 何时使用

- 用户说"按格式总结这篇论文 / 详细解读 / 总结 + 解读"
- 想要比一句话总结更详细、但比结构化翻译全文更紧凑的版本
- 用于论文浏览前的快速理解、或写作素材引用

## 解读模板（5段式，严格使用以下标题）

```
📌 核心贡献
[用 1-2 句话简洁总结论文的核心创新点或主要贡献]

❓ 研究问题
[清晰说明论文要解决的具体问题；简要解释该问题的研究意义或现有研究的不足]

🔑 关键方法
[用 3-5 个要点分条总结方法的核心思想，包括技术路线、模型设计、实验方案等关键环节]

📊 实验结果
[数据集/实验设置：说明实验使用的主要数据集、样本量、对比模型等设置]
[主要性能指标和对比结果：列出核心性能指标及与基线模型的对比数据]
[关键发现：总结实验得出的重要结论或现象]

💡 启发与局限
启发: [基于论文内容，提炼对后续研究有参考价值的思路或方向]
局限: [客观指出论文存在的不足，如数据集局限性、方法假设条件、实验设计缺陷等]
```

## 工作流

### 1. 获取论文内容
- arXiv 链接：WebFetch `https://arxiv.org/abs/<id>`（摘要 + 元数据）；需要方法细节再抓 `https://arxiv.org/html/<id>`。
- 本地 PDF：Read 工具读。
- 仅标题：WebSearch 定位。

### 2. 生成解读
按上面的 5 段式模板生成中文解读（500-1000 字）。**忠实原文**：所有数据/指标必须来自论文原文，无法确认的写"（待核实）"。

### 3. 创建解读文档
用 `doc/create_doc.py` 创建 doc：
- 标题：`（解读）[中文简译标题]英文原标题`
- 正文：上面 5 段模板填好的 markdown
- 父节点：论文根目录 `BgSQ6CbjAKeDk9qKLtGHCA`（如已确认相关）或待阅读区 `th8CPBrjAOWbnGgRWJ3mIt`（来自每日搜索）

### 4. 写入总表
用 `database/batch_add_database_records.py`（database-id=`OJLJkCoJSkV3TdHWBVEjhH`）：
- 必填：论文标题、作者/机构、年份、发表源、分类、状态、相关性、一句话总结、关键词
- 摘要类（**只填核心摘要**）：把上面 5 段解读**全文**写入 `中文结构化摘要` 字段（用 \n 分行），这样工作台阅读模式左栏"概要式总结"会渲染这份解读
- 详细翻译类（**留空**）：本 skill 不写 `详细章节翻译(带图)` 与 `配图`（那是「3dgs论文结构化翻译」skill 的输出）；如果用户后续要全文翻译，再用那个 skill 补充
- 5 格笔记字段留空
- 论文原文链接、结构化文档链接、添加日期=当天

写入前 query 总表按标题去重；已存在则用 `batch_update_database_records.py` 增量更新 `中文结构化摘要` 字段。

### 5. 回执
告知用户：解读文档链接 + 总表记录更新；说明这是"解读版"（如需全文+图片，用 3dgs论文结构化翻译 skill 进一步补充）。
