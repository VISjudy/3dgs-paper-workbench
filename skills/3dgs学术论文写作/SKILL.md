## 工作流

### 1. 收集素材
- 用资料库 skill（library）的 `database/query_database_record.py` 或 `get_database_content.py`（database-id=`OJLJkCoJSkV3TdHWBVEjhH`）拉全部记录。
- 优先使用 状态=已读已评价 的论文（用户已消化），其次 待精读，最后 待判断相关性（须标注"未精读，观点仅供参考"）。
- 需要某篇论文更多细节时，顺记录里的"结构化文档链接"读全文（doc 模块 get_doc_reviews.py）。

### 2. 与用户确认写作参数（缺省时不问，直接合理假设）
- 语言：中文（默认）或英文
- 目标形态：期刊论文 / 学位论文 / 开题报告
- 用户给的"论文方向"即主线

### 3. 生成章节（引用纪律最重要）

**摘要**（300–500字）：背景1-2句 → 问题/挑战 → 方法思路 → 结果与贡献。占位处用（占位）明确标出，不虚构实验数字。

**引言**（4段式）：
1. 大背景：3DGS 新视角合成与三维重建的意义（测绘/数字孪生场景）
2. 问题聚焦：结合资料库文献指出训练开销、多模态融合、几何精度、渲染伪影四大瓶颈中与用户方向相关的部分
3. 现有方法不足：点名具体文献并给出真实不足
4. 本文贡献：3条（占位，交用户确认）

**国内外研究现状**（核心章节）：
- 按四大方向分小节：训练加速 / LiDAR+图像多模态融合 / 几何质量增强 / 图像质量与伪影抑制
- 每小节：3–8 篇文献按时间线组织成"演进脉络"（不要流水账式罗列，要有逻辑连接词与递进关系）
- 每篇引用格式：作者（年份）在[发表源]提出…[一句话总结]，其局限在于…
- 每小节结尾：小结句指出该方向仍存在的 gap（这是用户论文的切入点）
- 中外归类：资料库未记录作者国别，如需"国内/国外"划分，按作者/机构字段中可辨识的机构判断，无法判断的归入"国际研究"并在文末提醒用户核实

**引用格式**：全文用 [N] 编号，文末列参考文献表（标题+年份+发表源+链接），与正文一一对应。

### 4. 铁律
- **绝不虚构**：论文没说过的话不写；不确定的结论加"（待核实）"
- 数字（提升幅度、参数量等）必须来自总表记录或结构化文档
- 待判断相关性的文献引用时在文末统一声明
- 输出为 Markdown；用户确认方向后可用 library skill 存成资料库文档
